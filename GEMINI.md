# Workspace Guidelines

- **Do Not Add Unrequested Content**: Never add headers, titles, subtitles, descriptions, placeholder copy, sections, or decorative elements that the user did not explicitly specify.
- **Follow Exact Instructions**: Only implement what the user directly asks for. Do not assume or extrapolate additional design elements or copy.
- **Do Not Unilaterally Alter Transitions or States**: Never lock, freeze, or fundamentally alter existing layout transitions, animation behaviors, or overlay states without explicit instruction.
- **Zero Comments**: Maintain strictly zero code comments anywhere in the codebase.
